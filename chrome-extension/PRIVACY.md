# Privacy Policy — Attendance Dashboard Launcher

Last updated: September 9, 2026

Attendance Dashboard Launcher is a Chrome extension that opens a teacher-configured Google Apps Script attendance dashboard and optionally stores shortcuts to a Google Form and Google Sheet.

## Data the extension stores

The extension may store the following configuration values in Chrome Sync storage:

- Google Apps Script teacher dashboard URL
- Google Form URL
- Google Sheet URL

These values are used only to launch the teacher's configured attendance resources.

## Student data

The extension does not collect, transmit, sell, or share student names, student IDs, attendance records, form responses, or spreadsheet contents.

Attendance records remain in the teacher's Google Sheet and are handled by the teacher's own Google Apps Script / Google Workspace configuration.

## Network activity

The extension itself does not send configuration data to an external analytics or advertising service. When the user opens the configured dashboard, form, or sheet, Chrome navigates to the corresponding Google URL and Google's own terms and privacy policies apply.

## Permissions

The extension requests only Chrome storage permission so it can remember the teacher's saved URLs across browser sessions and, when Chrome Sync is enabled, across the user's signed-in Chrome devices.

## Data sale and advertising

The extension does not sell user data and does not use user data for advertising, profiling, or unrelated purposes.

## Data deletion

Users can remove saved configuration by opening the extension settings and clearing the saved URLs, or by uninstalling the extension and clearing its extension data from Chrome.
